## 功能特性

- **功能丰富** – 商品页显示用户ID、转化率、信用等级标记，时长、好评率、卖出件数预警；个人页卖家信用分析，通过IP、时间、来源、好评率多维度分析
- **友好的视觉UI** – 界面简洁，配色于官网保持一致，设置按钮集成于原生侧边栏

## 快速开始

### 使用方式

**安装 violentmonkey 注入脚本**  
1. 访问 [violentmonkey](https://github.com/violentmonkey/violentmonkey) 或 在浏览器扩展市场中搜索并安装
2. 启用脚本注入权限：浏览器右上角扩展图标 -> 管理扩展 -> violentmonkey -> 详细信息 -> 允许用户脚本
